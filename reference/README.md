# Reference

Working material: research, costings, vendor comparisons, notes to self.

**Not application documentation, and deliberately not under `docs/`.** Everything
in `docs/` is bundled into the jar by the `<resources>` block in `pom.xml` and
shipped inside every package the `Makefile` builds, so a note that lands there
goes out to anyone who installs the application. The README's documentation table
and the Help menu are also expected to list the same pages, and a file here is in
neither.

Nothing in this directory is read by the application or by the build.
